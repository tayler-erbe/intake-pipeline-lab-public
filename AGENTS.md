# Rules for this repository

This is the PUBLIC, general-audience companion to the private repository tayler-erbe/intake-pipeline-lab.

- Write for a general audience, in the style of the Applied AI Lab briefs: plain language first, technical detail second.
- Publish the design, and results measured on GENERATED (fictional) documents, always labelled as generated. Owner decision, 14 November 2026.
- Never add real documents, document text, extracted values, institution names, private repository names or file paths. For runs on real documents, only how the models performed may appear (pages, time, stage counts), never anything from inside the documents.
- Never claim accuracy on real documents until a labelled pilot says otherwise.
- `brief/styles.css` and `brief/site.css` are shared Lab stylesheets; keep them identical to the other Lab briefs. Page-specific styles go in `brief/pipeline.css`.
