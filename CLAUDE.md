# Rules for this repository

This is the PUBLIC, general-audience companion to the private repository tayler-erbe/intake-pipeline-lab.

- Write for a general audience, in the style of the Applied AI Lab briefs: plain language first, technical detail second.
- Publish design only. Never add real documents, document text, extracted values, sample counts, institution names, private repository names, file paths, or results from real-document runs.
- Never claim accuracy. The pipeline has run only with placeholder models until a labelled pilot says otherwise.
- `brief/styles.css` and `brief/site.css` are shared Lab stylesheets; keep them identical to the other Lab briefs. Page-specific styles go in `brief/pipeline.css`.
